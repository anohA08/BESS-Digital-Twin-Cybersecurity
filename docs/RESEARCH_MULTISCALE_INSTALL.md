Extract `BESS_RESEARCH_MULTISCALE_AUDIT_ADDON.zip` directly into your existing BESS_REBUILD_STARTER folder. It adds only:

- `run_research_multiscale.py`
- `src/bess/research/multiscale_audit.py`
- `tests/test_research_multiscale.py`
- `docs/RESEARCH_MULTISCALE_STRESS_AUDIT.md`
- `docs/RESEARCH_MULTISCALE_INSTALL.md`

Existing Box 1–4, previous research candidate, and prior tests are untouched. Run tests and the runner, inspect the negative result, then commit only these paths. The new benchmark is not a claimed improvement.
